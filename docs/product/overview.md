# Product overview

**Company posture:** Doubt is an information utility for Solana meme-token discovery.

## Problem

Meme markets reward speed. Tools optimize for entry latency and FOMO. Traders learn the cost of a position **after** they are stuck: illiquid exits, cascade dumps, unlocked LP, narrative death.

## Solution

Doubt surfaces **exit cost** before entry.

- **Discovery feed** — browse tokens ranked by how survivable an exit looks  
- **Verdict** — structured analysis for any contract address (CA)  
- **No execution** — we never swap, never hold keys, never route orders  

## Target users

| Segment | Need |
|---------|------|
| Meme traders burned once | Second opinion before size |
| Users who see a CA on X | Fast, shareable risk read |
| Bag holders | Check if the book is dying |
| Researchers | Deployer / pool context over time |

## Non-users

- Bots farming alpha (rate-limited)  
- Pure speed traders (Photon / terminal users)  
- Anyone expecting in-app buy buttons  

## Positioning

| Competitors sell | We sell |
|------------------|---------|
| Speed | Exit math |
| Hype | Doubt |
| “Gem” signals | Cost-if-wrong |

## Product surfaces

1. **Radar** — ranked discovery  
2. **Fresh** — newest pairs  
3. **Fading** — deteriorating exit conditions  
4. **Verdict** — full report per mint  

## Success metrics (product)

- Users open a CA and understand exit cost within 10 seconds  
- Share rate of verdict screens (forwarded links / screenshots)  
- Return visits to check bags (not only FOMO entries)  

## What we will not build

- Wallet connect  
- Swap UI or deep-links that execute  
- Custody, bridging, or “copy trade”  
- Undisclosed paid rankings  

Sponsored placements, if any, will be **clearly labeled** and separated from organic scoring.
